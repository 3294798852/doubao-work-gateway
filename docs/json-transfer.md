# 两类 JSON，分别使用

| 文件 | 入口 | 内容 |
| --- | --- | --- |
| 账号备份 `doubao-work-accounts/v1`，version 3 | 工作台 | 登录资料、设备上下文、账号名、备注、转发和签到开关。文件含敏感会话 |
| 旧版账号备份，version 2 | 工作台 | 仅迁入豆包工作网页登录快照；不使用旧代理或第三方账号 |
| 接口节点 `doubao-work-nodes/v1`，version 1 | 接口节点 | Base URL、模型 ID、可选 API Key；默认不导出 Key |

账号备份导出时需确认敏感文件。导入最多 20 个账号、512 KB，先预览后确认。重复默认跳过；选择更新也只影响未核验的重复条目。新导入的账号显示「需检查登录」，可点击「核验备份」确认官方身份，也可重新浏览器登录。

## 迁移到其他电脑或无客户端服务器

1. 将网关或插件更新到 0.6.3 或更高版本。浏览器登录保存官网会话上下文，旧 Cookie 账号在实际使用时自动补齐。
2. 从工作台导出账号 JSON。`session` 保存 Cookie、设备号、指纹、Web/桌面会话类型和相应客户端元数据。Web 会话还包含官网返回的 `webId`、`appId` 和版本。
3. 在目标网关预览并导入备份，再点击「核验备份」。在 Magpie 中使用供应商账号导入入口。目标环境优先使用账号携带的设备信息。

`deviceId` 来自该用户的官网会话、已有完整快照、Cookie 或本机客户端。仅含 Cookie 的旧备份可直接在无客户端服务器导入，核验时自动取得官网上下文。账号会话失效时重新登录。[自动获取与验证记录](web-device-context.md)

0.5.2 已完成 Windows → WSL Ubuntu 隔离用户目录的真实账号迁移，Ubuntu 上的网关和 Magpie Bun 宿主均返回 `OK`。更换网络后，豆包返回的人工验证要求继续按账号状态处理。

接口节点每次最多 50 个、512 KB。远端地址只接受 HTTPS，本机可用 HTTP；不接受 URL 内置凭据。重复节点可更新；未提交 Key 字段时保留旧 Key。节点配置供客户端使用，不会修改网关实际转发目标。

需要迁移只剩数据库的旧账号时，先备份私有状态目录并停止旧服务，再运行 `node launcher.mjs migrate-legacy`（可附加原状态目录参数）。首次迁移保留原签到计划和同日签到状态；新库另存，旧库不改。迁入后仍需身份核验。
